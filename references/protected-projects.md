# Projects with additional operating restrictions

This public package contains no private trading-system paths, datasets, account state, deployment URLs or project-specific phase rules. A trading or research repository can be used like any other selected project, subject to its owner's additional limits.

Keep specialized instructions in that project's private governing documents. Establish the selected root and current instructions before acting. Preserve runtime history and unrelated changes. Read-only status checks should distinguish current process identity from stale saved status; missing evidence is not proof of success or failure.

Do not infer authorization to enable live trading, send orders, alter risk settings, start workers or change provider routing from a request to inspect or repair software. Tests passing does not establish research validity or financial readiness. Follow the user's actual scope and current project rules; this generic guide does not import any previous user's private workflow.
